৬. Step-by-Step Complete Work Flow
Step 1: Shopify Product Sync
Admin app install বো connect করার পর Express backend Shopify থক সংগ্রহ করবে: Product, Variants,
Images, Price, Options, Inventory, Metafields.
MongoDB-এর products collection-এ Shopify ID সংরক্ষণ করবেনে।
Sync trigger: App installation, Manual sync, Product update webhook, Product delete webhookStep 2: Admin Customizer Setup
Product
  ├── Front mockup
  ├── Back mockup
  ├── Left-side mockup
  ├── Right-side mockup
  ├── Print area
  ├── Safe area
  ├── Bleed area
  ├── Allowed tools
  ├── Fonts
  ├── Cliparts
  └── Pricing rules
Print area save করবেনে normalized coordinate হসবে:
{
  "x": 0.22,
  "y": 0.18,
  "width": 0.56,
  "height": 0.64
}
এভাবে desktop, mobile এবেং high-resolution export-এ একই print-area ratio রাখা যোবে।
Step 3: Customer Opens Customizer
Shopify product page-এর Customize button user-ক পাঠাবে:
https://customizer.example.com/customize/t-shirt
?product=gid://shopify/Product/123
&variant=gid://shopify/ProductVariant/456
Frontend backend থক load করবে: Product information, Selected variant, Mockups, Print areas, Allowed
customization tools, Existing design, Pricing rules.
Step 4: Initialize Canvas
Fabric Canvas তৈর করবে।
Product mockup background হসবে বেসাবে।
Print area clip path তৈর করবে।• 
• 
• Safe-area guideline খাবে।
Product view অনেুযোয়ী canvas state load করবে (Front View → frontCanvasJSON ইতৈধ্যো)।
Step 5: Customer Customizes Product
Canvas tools (Upload, add text, etc.)। প্রতৈটি object-এর custom metadata রাখবেনে:
{
  "id": "object_uuid",
  "type": "image",
  "assetId": "asset_id",
  "view": "front",
  "printable": true,
  "locked": false
}
Step 6: Canvas State Management
Zustand store-এর মধ্যে পুরা Fabric object রাখবেনে নো। Store-এ রাখবেনে: Selected object ID, Active product
view, Zoom level, Undo/redo state, Dirty state, Pricing selections, Canvas JSON snapshot।
Step 7: Image Upload Pipeline
Customer selects file
        ↓
Frontend validates size/type
        ↓
Express generates presigned upload URL
        ↓
Browser uploads directly to S3
        ↓
Express saves asset metadata
        ↓
Processing job starts
        ↓
Optimized image returned
Upload validations: MIME type, File extension, Magic bytes, Max size, Dimensions, Transparent PNG,
SVG sanitization, Virus scanning, hash detection.
Step 8: Client-Side Image Processing
ছাট operations client-side করা যোয়: Thumbnail generation, Crop preview, Brightness preview, Contrast
preview, Background preview, Low-resolution warning। Heavy processing Web Worker-এ পাঠাবেনে।• 
• Step 9: Autosave System
Local autosave (IndexedDB) এবেং Server autosave (Send compressed JSON)।
Step 10: Preview Generation
Instant preview (browser PNG/WebP) এবেং Production preview (Backend worker high-resolution
rendering)।
Step 11: Print-Ready Export
Print width ও desired DPI থক output pixels calculate করবেনে:
Pixel Width  = Print Width in Inches × DPI
Pixel Height = Print Height in Inches × DPI
Production manifest
{
  "designId": "DES-10001",
  "product": "Premium T-Shirt",
  "variant": "Black / XL",
  "printMethod": "DTG",
  "views": [
    {
      "name": "front",
      "widthInches": 12,
      "heightInches": 16,
      "dpi": 300,
      "file": "print-front.png"
    }
  ]
}

১৩. Security Features
HTTP-only secure cookie, JWT/session rotation, Role-based permissions, Zod request validation, Rate
limiting, Helmet security headers, Strict CORS, Shopify webhook HMAC verification, File signature
validation, SVG sanitization, Presigned upload URLs, Short-lived download URLs, Idempotency key,
Audit logs, Admin 2FA, Private S3 bucket।১৪. Performance Optimization
Frontend:  Canvas editor dynamic import, Disable SSR for canvas, Memoized toolbar , Debounced
autosave, Lazy-load cliparts, Web Worker processing, Mobile reduced preview.
Backend:  Redis cache, BullMQ workers, MongoDB indexes, S3/CDN assets, Cursor pagination,
Compressed Canvas JSON, Idempotency, API vs image workers.

Design Autosave Flow
Canvas change
   ↓
Frontend debounce
   ↓
Update design_views
   ↓
Increment designs.currentRevision
   ↓
Generate low-resolution preview
   ↓
Update designs.viewSummary
এই operation transaction-এর মধ্যে করা উচেতৈ।
Add to Cart Flow
Validate current design
        ↓
Calculate price on backend
        ↓
Create design_versions
        ↓
Copy current states to design_version_views
        ↓
Mark version locked
        ↓
Create/update cart_sessions
        ↓
Add Design ID and Version ID to Shopify cart
Cart-এ mutable designId ছাড়াও locked designVersionId রাখতৈ হবে।Order Creation Flow
Shopify orders/create webhook
        ↓
Verify HMAC
        ↓
Check webhook_events unique ID
        ↓
Create orders
        ↓
Create order_items
        ↓
Attach locked designVersionId
        ↓
Create export_jobs
        ↓
Generate production files
Transaction Boundaries
Transaction 1: Save Design
Update design_views, Update designs.currentRevision, Update designs.lastAutosavedAt
Transaction 2: Lock Design Version
Create design_versions, Create design_version_views, Update designs.latestVersionId, Update
designs.status
Transaction 3: Order Webhook
Create webhook_events, Create orders, Create order_items, Create export_jobs
